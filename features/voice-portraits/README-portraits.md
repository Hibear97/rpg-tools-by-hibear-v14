# Голосовые портреты (Voice Portraits) для Foundry VTT v13

Панель портретов персонажей рядом со списком игроков (внизу слева).
Портреты реагируют на голос, меняют эмоции, а сообщения чата появляются облачками у портретов.

## Установка

1. Распакуйте архив в папку данных Foundry: `Data/modules/rpg-tools-by-hibear/` (общий модуль RPG Suite)
   (внутри должны лежать `module.json`, `scripts/`, `styles/`).
2. Перезапустите Foundry, откройте мир → **Настройки → Управление модулями** → включите «Голосовые портреты».
3. Модуль нужен только на сервере: игрокам ничего ставить не нужно (кроме случая с Телемостом, см. ниже).

---

## Откуда берётся голос

| Как вы общаетесь | Что настроить | Учитывает рацию и мут |
|---|---|---|
| **Discord (приложение)** | Discord-бот у мастера | ✅ точно, для всех игроков |
| **Яндекс Телемост (в браузере)** | Tampermonkey + скрипт у каждого игрока | ✅ |
| **Голосовой чат Foundry** | Нужен https (SSL) | ✅ |
| Discord без бота | ничего | ❌ реагирует на любой звук в микрофоне |

Если Foundry открыт по `http://` (без SSL), браузер **не даёт** игрокам доступ к микрофону.
Discord-бот и скрипт для Телемоста не используют микрофон в Foundry, поэтому работают и без https.

### Вариант А. Discord-бот (рекомендую)

Бот сидит в голосовом канале с выключенным звуком и видит, кто **реально передаёт голос** в Discord и насколько громко.
Режим рации, мут и наушники учитываются сами собой. Звук бот никуда не пишет и не сохраняет.
Запускает бота **только мастер**, на том же компьютере, где у него открыт Foundry.

**1. Создать бота (один раз, ~5 минут)**
1. Откройте <https://discord.com/developers/applications> → **New Application** → назовите, например, «Портреты».
2. Слева **Bot** → **Reset Token** → скопируйте токен (никому его не показывайте).
3. Слева **OAuth2** → **OAuth2 URL Generator**:
   - в **Scopes** отметьте `bot`;
   - в **Bot Permissions** отметьте `View Channels` и `Connect`.
4. Скопируйте ссылку внизу страницы, откройте её и добавьте бота на свой сервер.

**2. Запустить бота**
1. Установите **Node.js 24 LTS** с <https://nodejs.org>.
2. Откройте папку `Data/modules/rpg-tools-by-hibear/features/voice-portraits/bot/` и запустите `start-windows.bat` (Windows) или `start-macos.command` (macOS). Подробно — в файле «КАК ЗАПУСТИТЬ.txt» там же.
   Бот сам перенесётся в постоянную папку вне модуля (Windows: `%LOCALAPPDATA%\RPG-Tools\discord-bot`, macOS: `~/Library/Application Support/RPG-Tools/discord-bot`) и сделает ярлык «RPG-Tools Discord-бот» на рабочем столе. Обновления модуля через Foundry его не затрагивают: токен и зависимости хранятся там, а новый код бот при запуске сам забирает из папки модуля.
   При первом запуске он создаст `config.json` и откроет его в блокноте: вставьте токен в поле `"token"`, сохраните и запустите бота ярлыком.
   Первый запуск ставит зависимости, это займёт минуту.
3. Бот сам зайдёт в голосовой канал, где больше всего людей. Чтобы он ходил за конкретным человеком, впишите его ник в `"followUser"`, например ник мастера.
4. Пока идёт игра, окно бота не закрывайте.

**3. Настроить в Foundry**
1. Настройки модуля → **Discord-бот: включить** ✔. В углу появится «Discord-бот подключён».
2. Каждый игрок (или мастер за него): правый клик по портрету → **Настроить портрет…** → **Ник в Discord**.
   Подходит имя пользователя, отображаемое имя, ник на сервере или ID.
   Под полем показывается, найден ли игрок в голосовом канале.
3. Громкость, с которой портрет «кричит»: настройка **Discord-бот: порог крика**.

> Если Foundry открыт по https (например, через Cloudflare), браузер мастера может спросить разрешение на «доступ к локальной сети». Разрешите.

### Вариант Б. Яндекс Телемост

У Телемоста нет API для ботов, поэтому каждый игрок ставит небольшой скрипт в браузер.
Скрипт смотрит, *что именно уходит в звонок*: при выключенном микрофоне туда идёт тишина, и портрет не двигается.

1. Установите расширение **Tampermonkey** (Chrome, Яндекс Браузер, Edge, Firefox).
2. Откройте Tampermonkey → **Создать новый скрипт**, удалите шаблон, вставьте содержимое файла
   `userscript/voice-portraits-telemost.user.js` и сохраните (Ctrl+S).
3. **Важно:** в Chrome, Edge и Яндекс Браузере на странице расширений (`chrome://extensions` или `browser://extensions`) включите **«Режим разработчика»**, а в настройках Tampermonkey — **«Разрешить пользовательские скрипты»** (если такой пункт есть). Без этого новые версии браузеров не запускают скрипты.
4. Перезагрузите вкладки Телемоста и Foundry, после того как скрипт установлен.
5. Телемост должен быть открыт **в браузере**, не в приложении.

Проверка: правый клик по своему портрету → «Настроить портрет…». В строке «Голос сейчас берётся из» должно быть «Яндекс Телемоста».
Там же есть индикатор и ползунки порогов речи и крика.

Этот же скрипт работает и с Discord, открытым в браузере (discord.com), но бот надёжнее.

### Вариант В. Голосовой чат Foundry

Нужен SSL-сертификат (https). Включается в «Настройке аудио/видео» → Режим конференции: «только аудио».
В настройках модуля поставьте **Источник голоса: Foundry**.

## Портреты

**Привязка к персонажу.** Набор картинок хранится у **персонажа**, который закреплён за игроком в Foundry (Настройки игрока → Персонаж).
Если игроку назначить другого персонажа, портрет сразу сменится на набор этого персонажа.
Если персонаж не закреплён, набор хранится у самого игрока.

**Размер** (маленький, средний, большой) задаёт мастер в настройках модуля. Он одинаков у всех.

**Правый клик по своему портрету:**
- **Эмоция**: Обычное, Радость, Грусть, Злость, Удивление, Страх, Ранен, Презрение. Эмоцию видят все.
- **Выключить микрофон.** Работает только для голосового чата Foundry и микрофона в браузере. Если голос идёт через Discord-бота или Телемост, выключайте микрофон там: портрет это увидит сам.
- **Настроить портрет…**:
  - имя на табличке;
  - режим: **Реагирует на голос** или **Статичный**;
  - ник в Discord;
  - картинки: основной портрет, «Говорит», «Кричит» и по одной на каждую эмоцию.

Как выбирается картинка:
- **Кричит** → картинка «Кричит», если она задана. Портрет трясётся, рамка светится оранжевым.
- **Говорит** и у текущей эмоции нет своей картинки → картинка «Говорит», если она задана. Портрет покачивается в такт голосу, рамка светится зелёным.
- **Иначе** показывается картинка эмоции или основной портрет.

**Правый клик по чужому портрету** (только голосовой чат Foundry) открывает громкость этого игрока.
Мастер может менять эмоции и портреты всех игроков.

**Панель можно перетащить** за полоску слева. Двойной клик по полоске возвращает её на место.

**Горячие клавиши.** В «Настроить управление» можно назначить клавиши на каждую эмоцию.

## Облачка чата

Сообщения игроков показываются облачком у портрета автора, а над их токенами на поле облачка не дублируются.
Реплики NPC от мастера остаются над токенами. Броски показываются по желанию (настройка «Облачка для бросков»).

## Для макросов

```js
game.voicePortraits.setEmotion(game.user, "contempt");   // сменить эмоцию
game.voicePortraits.setEmotion("Аня", "happy");          // мастер — для другого игрока
game.voicePortraits.openConfig();                        // окно настройки
```
Эмоции: `neutral, happy, sad, angry, surprised, scared, hurt, contempt`.

## Совместно с BG3 Style HUD

Если включён модуль **BG3 Style HUD**, портреты встраиваются в его интерфейс (это можно выключить в настройках BG3 Style HUD → «Голосовые портреты: встроить в интерфейс»):
- ваш портрет — в круге слева от скиллбара: двигается под голос, подсвечивается, меняет картинку «говорит/кричит» и эмоции; там же облачко чата и кнопка микрофона; ПКМ по кругу — меню эмоций;
- портреты остальных игроков и мастера — вертикальной колонкой слева экрана, с полоской хитов персонажа;
- клик по портрету в колонке — показать токен персонажа (свой — выделить), двойной клик — открыть лист.

Для модулей доступно API: `game.voicePortraits.getConfig(user)`, `getEmotion(user)`, `pickImage(user, cfg, emotion, state)`, `emotionList`, `openMenu(user, event)` и хук `voicePortraits.bubble (userId, text, {emote})`.
