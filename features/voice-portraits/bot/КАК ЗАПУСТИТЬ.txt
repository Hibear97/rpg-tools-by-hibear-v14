ГОЛОСОВЫЕ ПОРТРЕТЫ — DISCORD-БОТ
================================

Бот один и тот же для Windows и macOS, отличается только файл запуска:
  • Windows — start-windows.bat
  • macOS   — start-macos.command

ВАЖНО: запускайте бота на том компьютере, где МАСТЕР открывает Foundry в браузере.
К боту подключается браузер мастера по адресу ws://127.0.0.1:30500.
Сам модуль к папке бота не обращается — только к запущенному боту по этому адресу,
поэтому путь к боту в Foundry указывать не нужно.

ОБНОВЛЕНИЯ МОДУЛЯ БОТА НЕ ЛОМАЮТ
При первом запуске из папки модуля бот сам переносится в постоянную папку:
  • Windows — %LOCALAPPDATA%\RPG-Tools\discord-bot
  • macOS   — ~/Library/Application Support/RPG-Tools/discord-bot
Там хранятся токен (config.json) и зависимости — Foundry их не трогает, когда обновляет модуль.
На рабочем столе появляется ярлык «RPG-Tools Discord-бот» — дальше запускайте бота им.
Когда модуль обновился, ярлык при запуске сам забирает новую версию бота из папки модуля.
Старый config.json из папки модуля переносится автоматически — токен заново вводить не нужно.

----------------------------------------------------------------
1. ОДИН РАЗ: СОЗДАТЬ БОТА В DISCORD
----------------------------------------------------------------
1) https://discord.com/developers/applications → New Application → имя, например «Портреты».
2) Слева Bot → Reset Token → скопируйте токен. Никому его не показывайте.
3) Слева OAuth2 → OAuth2 URL Generator:
     Scopes: bot
     Bot Permissions: View Channels, Connect
4) Откройте ссылку снизу страницы и добавьте бота на свой сервер.

----------------------------------------------------------------
2. WINDOWS
----------------------------------------------------------------
1) Установите Node.js 24 LTS с https://nodejs.org (всё по умолчанию).
2) Дважды щёлкните start-windows.bat (в папке модуля: Data\modules\rpg-tools-by-hibear\features\voice-portraits\bot).
   Бот перенесётся в постоянную папку, на рабочем столе появится ярлык «RPG-Tools Discord-бот».
3) Откроется Блокнот с config.json — вставьте токен в поле "token", сохраните (Ctrl+S), закройте.
4) Запустите бота ярлыком на рабочем столе. Первый запуск ставит зависимости (~1 минута).
5) Пока идёт игра, окно бота не закрывайте.

Если Windows покажет «Система Windows защитила ваш компьютер» — «Подробнее» → «Выполнить в любом случае».

----------------------------------------------------------------
3. macOS
----------------------------------------------------------------
1) Установите Node.js 24 LTS с https://nodejs.org (файл .pkg).
2) Дважды щёлкните start-macos.command.
   Если macOS пишет, что файл «не может быть открыт» или «от неустановленного разработчика»:
     правый клик (или Control+клик) по файлу → «Открыть» → «Открыть».
   Если пишет, что нет прав на запуск — откройте Терминал и выполните (перетащите файл в окно Терминала вместо пути):
     chmod +x путь/к/start-macos.command
   Бот перенесётся в постоянную папку, на рабочем столе появится ярлык «RPG-Tools Discord-бот».
3) Откроется TextEdit с config.json — вставьте токен в поле "token", сохраните (Cmd+S), закройте.
   Если TextEdit заменит прямые кавычки на «ёлочки» или “фигурные” — бот не запустится.
   Отключите: TextEdit → Настройки → снимите «Смарт-кавычки», или правьте файл в любом редакторе кода.
4) Запустите бота ярлыком на рабочем столе. Первый запуск ставит зависимости (~1 минута).
5) Пока идёт игра, окно Терминала не закрывайте.
   Если браузер (Safari/Chrome) спросит разрешение на «доступ к устройствам в локальной сети» — разрешите.

----------------------------------------------------------------
4. В FOUNDRY
----------------------------------------------------------------
1) Мастер: центр управления (Shift+M) → Голосовые портреты → «Discord-бот: включить» → Сохранить.
2) Должно появиться «Discord-бот подключён», а в окне бота — «Foundry подключился».
3) Каждый игрок указывает ник в Discord: правый клик по своему портрету → «Настроить портрет…».

----------------------------------------------------------------
НАСТРОЙКИ config.json
----------------------------------------------------------------
  token      — токен бота (обязательно)
  followUser — ваш ник в Discord: бот будет заходить в тот канал, где сидите вы (необязательно)
  guildId    — ID сервера Discord, если бот добавлен на несколько серверов (необязательно)
  host, port — адрес, на котором бот ждёт Foundry. Обычно не трогать.
               Бот на другом компьютере (только если Foundry открыт по http://):
               "host": "0.0.0.0", а в Foundry «Discord-бот: адрес» = ws://IP-этого-компьютера:30500
               и откройте порт 30500 (TCP) в брандмауэре.

Если Foundry стоит на другом компьютере или на хостинге (Forge и т.п.), скопируйте папку bot
на компьютер мастера куда угодно и запускайте start-windows.bat / start-macos.command оттуда —
бот будет жить в этой папке. Зависимости переустанавливаются сами при смене системы или версии.

Где лежит токен: config.json в постоянной папке бота (см. выше). Окно бота при запуске пишет точный путь.
